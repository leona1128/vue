這是一個使用 Vue 3 製作的便利貼應用：</br>
新增/刪除代辦事項</br>
編輯事項內容與日期</br>
自動儲存至瀏覽器（localStorage）</br>
新增多張便利貼（不同顏色）</br>
使用技術：</br>
Vue 3 + <script setup></br>
Composition API</br>
LocalStorage 持久化資料</br>
基本 HTML/CSS 排版</br>
專案結構：</br>
src/
├── components/
│   └── todoApp.vue        # 單張便利貼元件
├── App.vue                # 外層容器，可新增多張便利貼
└── main.js                # Vue 應用啟動點
